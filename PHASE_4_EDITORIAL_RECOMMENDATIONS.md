# Phase 4 – Editorial Recommendations (L2 + L3)

**Status: recommendations only.** Nothing in WordPress/Yoast has been changed. Every value below is edited in the WordPress admin (Yoast SEO box → *SEO title* / *Meta description* of each page, service or portfolio item). The frontend shows Yoast's values as they are, so changes appear on the site within the normal cache window (5 minutes for service, blog and portfolio pages; up to 5 minutes for static pages).

**Data source:** the server HTML of the local Phase 4 build (identical Yoast data to staging), 2026-11-16. Character counts are of the rendered text.

**How the suggestions were written**
- Only words that are already in the current title or description are used. Segments were removed or reordered and connecting words adjusted. No new services, numbers, rankings, locations or claims were added.
- Titles target ≤ 60 characters and end with `| Grehasoft`, the form most pages already use. Descriptions target ≤ 160 characters.
- These are common display guidelines, not hard limits: Google may still rewrite titles and snippets. Pages that are slightly over the limit are low priority.
- Items marked **content error** are mistakes in the current Yoast text and are worth fixing whatever is decided on length.

## Brand spelling (L3)

Titles use two spellings. **"GrehaSoft"** appears as the "- GrehaSoft" suffix on items that seem to use Yoast's default `%%title%% %%sep%% %%sitename%%` title template: all 8 portfolio items, several blog posts and the category archives ("SEO Archives - GrehaSoft"). This suggests the WordPress site name is "GrehaSoft". Hand-written titles use **"Grehasoft"**, as does the site's visible copy.

**Recommendation:** decide on one spelling (the site copy suggests "Grehasoft"), then in WordPress:
1. *Settings → General → Site Title*: set to the chosen spelling (this is Yoast's `%%sitename%%`). Check first whether the site title is shown anywhere else.
2. Or override the SEO title of each affected portfolio item.

The frontend fallback title `"GrehaSoft"` in `app/page.tsx` (used only if Yoast returns no title) and `"Blogs | GrehaSoft"` in `app/blogs/page.tsx` can be aligned in code once the spelling is confirmed. This needs a one-line code change, so it was not made without approval.
